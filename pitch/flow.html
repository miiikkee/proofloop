ProofLoop: find it, fix it, prove it

A fix is accepted only on independent browser evidence, never on the model's confidence.
0Operator runs python app.py --scenario allCLI

Orchestrator state machine with safety gates, max 2 attempts, per-step timeouts

1Provision isolated sandboxDaytona

Ephemeral sandbox · baseline copy :3000 and candidate copy :3001, kept separate · each behind a signed, expiring preview URL

2Detect: run 3 fixed acceptance checks on baselineAnchor Browser

Cloud Chromium via Playwright-over-CDP · homepage · contact page · submit shows "Thank you" → 2/3 + screenshot + failure evidence

3Recall prior outcomes for this symptomSurrealDB Agent Memory

Verified and failed fixes from earlier runs, each traceable to its run id · passed to the model as untrusted hints

4Diagnose and propose a patchClaude Sonnet 5.5 · AWS Bedrock

Input: browser evidence + allowlisted templates + read-only backend · Output: JSON {root_cause, file_path, find_text, replace_text, reason, confidence}

5Safety gate (deterministic, outside the LLM)Code

Exact file allowlist · find_text occurs exactly once · ≤300 chars · no scripts, handlers, external URLs or secrets

Rejected → store as "do not repeat" in SurrealDB, feed the reason back, retry (attempt 2 of 2)
6Patch the candidate copy only and run fixed testsDaytona

Baseline is never touched · developer-defined commands only (py_compile, Flask route tests) · no model-generated shell

7Verify independently on the candidate previewAnchor Browser

Fresh cloud browser session · the same 3 checks, unchanged by the agent

All 3 pass 3/3
Store a verified fix in SurrealDB (supersedes failed attempts) → report, diff, before/after screenshots → status verified_awaiting_human_approval. No auto-merge, no deploy.
Still failing
Store as failed fix → reset candidate to baseline → retry with failure context. After 2 attempts: unverified_discarded.
8Cleanup and evidenceReport

Signed URLs expired · sandbox deleted · run_report.json with real pass counts, timings, baseline_copy_modified=false

Arize AX: traces every step

  • Spans: provision · detect · memory.recall · diagnose · patch · test · verify · memory.remember
  • Bedrock LLM calls with token counts

  • Run input/output and OK/ERROR status

Guardrails

  • Baseline and candidate always separate
  • Checks written by the developer, never by the model
  • Memory is a hint, not an authority
  • Page text and memory treated as untrusted
  • Preview tokens redacted from logs
  • A person approves before any adoption
